# APKS-Lab1-AI-Agent
APKS Lab 1 — AI Agent Development Automation

## Project

Minimal Java 21 Hello World application for the `apks-lab1-hello` project.

The application uses the `com.apks` package and is located at:

```text
src/main/java/com/apks/App.java
```

## Requirements

- Java Development Kit (JDK) 21
- Apache Maven (build configuration will be added separately)

## Application

After Maven configuration is added, use Maven to compile and run the project:

```text
mvn compile
java -cp target/classes com.apks.App
```
